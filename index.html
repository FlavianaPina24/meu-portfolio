Visão de Negócios e Qualidade (BA & QA)

Como Business Analyst, idealizei este portfólio focando na jornada do usuário. O objetivo era criar uma experiência fluida para recrutadores e Tech Leads, garantindo que as informações essenciais (como meu currículo e contato) estivessem acessíveis a um clique.

Como QA, o trabalho não terminou no layout. Desenvolvi um ecossistema de Qualidade Contínua para "proteger" este site! Os vídeos em destaque demonstram meu framework em Playwright + Java executando testes de ponta a ponta (E2E), validando funcionalidades críticas da aplicação.

  • Levantamento de Requisitos e Design focado em UX (BA)
  • Mapeamento de Testabilidade com atributos exclusivos data-testid (QA)
  • Integração Contínua (CI/CD) com Nightly Builds no GitHub Actions

Formulário de Contato

O robô mapeia os campos de texto dinamicamente, centraliza a câmera de forma suave e digita os dados simulando a interação de um usuário real.

Interação Modal E2E

A automação abre o pop-up, espera as animações carregarem, preenche os dados utilizando boas práticas de data-testid e valida o fechamento da janela no sistema.
