## 📖 Diário de Bordo & Rascunhos

### Rascunho de Lançamento (LinkedIn)

**O futuro do QA não é apenas sobre escrever código do zero, é sobre saber resolver problemas e entregar valor com visão estratégica.** 🚀

Nas últimas semanas, decidi construir meu portfólio profissional. Como minha maior senioridade e paixão sempre estiveram na **Análise de Negócios (BA)** e nos **Testes Funcionais/Exploratórios**, o desafio técnico de criar um site web do zero e ainda automatizá-lo parecia distante.

Foi aí que decidi colocar em prática o conceito de **AI-Augmented QA** (QA Potencializada por IA). 🤖💡

Em vez de recuar, convidei o Google Gemini para ser meu "Pair Programmer". Utilizando meus conhecimentos de lógica, estratégia de qualidade e engenharia de prompt, orquestrei a Inteligência Artificial para materializar a minha visão de negócios. O resultado?

✅ Um site responsivo com painel interativo de Acessibilidade Inclusiva (A11y).
✅ Framework E2E estruturado em **Java + Playwright** executando 12 cenários complexos.
✅ Automação de API (Rest-Assured + BDD) abordando testes de contrato e resiliência.
✅ Blindagem Cibernética (DevSecOps) mitigando injeções XSS e DDoS, validadas pelo OWASP ZAP.
✅ Auditoria autônoma de acessibilidade na esteira com a biblioteca **Axe-Core**.
✅ Uma esteira de **Integração Contínua (CI/CD)** no GitHub Actions gerando relatórios com evidências em Base64.

Acredito fortemente que a transparência é o nosso maior diferencial no mercado. Ter a sinceridade de reconhecer onde somos especialistas e usar a Inteligência Artificial como alavanca para construir produtos com excelência técnica é a minha visão sobre o QA moderno.
