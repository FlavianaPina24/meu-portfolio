2 O Comando de Ouro: Como Auditar Qualquer Site de Cliente

Este é o comando mais importante do seu negócio. Ele roda todos os 9 pilares de auditoria, tira prints automáticos, aciona a IA e gera o relatório completo para o site que você indicar:

# Substitua a URL pelo site do cliente: mvn test -DtargetUrl="https://site-do-cliente.com.br"

Exemplo real auditando o seu próprio portfólio:

mvn test -DtargetUrl="https://flavianapina.com.br"

Tempo de execução estimado: de 40 a 90 segundos. O Playwright abrirá as abas em segundo plano, executará todos os testes e consolidará os resultados.

3 Os 9 Pilares Auditados Automaticamente

Pilar de Auditoria O que a Automação Faz Valor para o Cliente
1. Acessibilidade (A11y) Varredura completa com Axe-Core (WCAG 2.1 A e AA), listando seletores violados e impacto. Evita processos jurídicos e garante inclusão digital.
2. Estrutura Semântica Verifica tags <html lang>, landmarks <main> e hierarquia. Permite navegação correta por leitores de tela.
3. Headings & Inicial Garante presença correta de <title>, <h1> e estrutura de cabeçalhos. Boas práticas de engenharia de software.
4. Imagens & Textos Alt Localiza todas as tags <img> sem descrição alternativa (alt). Melhora indexação no Google e acessibilidade.
5. Links Quebrados Varre todos os links <a> e detecta rotas quebradas ou links vazios. Elimina erros 404 e melhora retenção de usuários.
6. SEO Técnico Inspeciona meta description, canonical, robots.txt, sitemap e Open Graph. Aumenta o tráfego orgânico e cliques no Google.
7. Segurança Web Audita cabeçalhos HTTP (HSTS, CSP, X-Frame-Options) e Reverse Tabnabbing. Protege contra ataques de Clickjacking e Phishing.
8. Performance Web Vitals Coleta TTFB (resposta do servidor), FCP e tempo total de carregamento via API. Acelera o site e reduz taxa de rejeição (*churn*).
9. Regressão Visual Compara screenshots pixel a pixel contra baselines com mapa de diffs. Garante que atualizações não quebrem o layout.

4 Onde Fica o Relatório e Como Entregar ao Cliente

Assim que o comando mvn test termina, os arquivos de entrega são gerados em:

C:\Users\Flaviana Pina\OneDrive\Área de Trabalho\qa-audit-toolkit\target\test-reports\

Os 2 ativos principais gerados:

  • Arquivo HTML do Relatório Executivo: Tem o nome no formato:
    Auditoria_Website_DD-MM-YYYY_HH-mm-ss.html
    (Basta dar 2 cliques nele para abrir no navegador Edge ou Chrome).
  • Pasta de Screenshots:
    target\test-reports\screenshots\
    (Contém prints automáticos de tela cheia com todas as evidências visuais coletadas).

Como enviar para o seu cliente:

  1. Opção 1 (Mais Recomendada - Arquivo HTML Completo): Compacte o arquivo HTML e envie por e-mail ou WhatsApp. O relatório é 100% autossuficiente (todos os gráficos e prints já estão embutidos em Base64 dentro dele, não depende de internet para abrir).
  2. Opção 2 (PDF Executivo): Abra o arquivo HTML no seu navegador (Google Chrome), aperte Ctrl + P, selecione "Salvar como PDF" e envie o PDF pronto e assinado para o cliente.

5 Cheat Sheet de Comandos Especiais

Comandos úteis para situações específicas do dia a dia:

A) Ver o navegador abrindo na sua tela (Modo com interface visual):

mvn test -Dheadless=false -DtargetUrl="https://site-do-cliente.com.br"

B) Rodar apenas a Auditoria de Acessibilidade com Axe-Core:

mvn test -Dtest=AuditTest#auditarAcessibilidadeAxe -DtargetUrl="https://site-do-cliente.com.br"

C) Rodar apenas a Auditoria de Segurança de Cabeçalhos HTTP:

mvn test -Dtest=AuditTest#auditarHeadersSeguranca -DtargetUrl="https://site-do-cliente.com.br"

D) Atualizar a Foto de Referência para Teste Visual (Criar Novo Baseline):

mvn test -Dtest=AuditTest#auditarConsistenciaVisual -Dupdate.snapshots=true -DtargetUrl="https://site-do-cliente.com.br"

E) Ativar o Consultor de IA Google Gemini (Recomendações Automáticas de Código):

# No PowerShell, antes de rodar o teste, defina sua chave da API: $env:GEMINI_API_KEY = "sua-chave-gemini-aqui" mvn test -DtargetUrl="https://site-do-cliente.com.br"

7 Solução de Problemas Comuns (Troubleshooting)

1. Erro: "Playwright browsers not found"
Se você formatar ou rodar em outro computador, instale os navegadores com um único comando:
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI -D exec.args="install --with-deps"

2. Erro de versão do Java
O seu projeto exige Java 17+. Você já possui o Java 21 instalado perfeitamente no seu computador. Para conferir, digite: mvn -version.
